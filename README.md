Verdict Friday — a real Black Friday deal finder. 39 deals from Amazon, Best Buy, Walmart, Target and Newegg, each price-checked on 27 Nov 2026, with sale price, usual price, discount % and an honest verdict (Strong deal ≥40% off, Good deal 20–39%, Weak deal under 20%). Search, category / store / discount filters and sorting run entirely in the browser from static files — no network, no tracking. Full price provenance for every deal is in DOSSIER.md.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 — or just open `app/index.html` in a browser.
